* Scope and operation

This is the source of truth. Edit this file, then run =M-x et/tangle-config=
and restart Emacs. Generated Lisp is kept alongside the source so startup
does not need to load Org. Do not edit generated files directly.

This configuration provides Evil, leader keys, minibuffer and in-buffer
completion, project workspaces, a tree, pop-up rules, theme previews, and Org
planning/roam workflows. IDE tools will follow separately. Nothing relocates notes.
The note root is =~/org=, with one roam graph in =~/org/roam= organized into
personal/work/general domains. These domains are not security boundaries.

Built-in =package.el=, =package-vc=, and =use-package= avoid a bootstrap
framework. Package installation is explicit via =M-x et/install-packages=;
startup never refreshes archives or installs packages. Packages are not locked
to exact versions yet. Archives use HTTPS, but this is not a claim of fully
reproducible builds. Packages that are not published on a configured archive
are cloned from source with a =package-vc= recipe, which needs Git.

Custom functions and variables use the =et/= prefix. Module file names and
provided features retain =et-= (for example, =et-core.el= and =et-core=).

All local packages and state live in =.local/= under this configuration, ignored
by Git. Optional machine settings go in =.local/settings.el=; credentials belong
in =auth-source=, not here. Customize writes to =.local/custom.el=, which is not
automatically loaded: promote intentional settings into this Org document.

* Early initialization

Disable Emacs's automatic package activation so init can select our isolated
package directory first. No global bidi or aggressive GC tweaks.

    "Explicitly refresh archives and install missing dependencies, not upgrades."

* Editing, paths, and leader maps

Use built-in history, saved cursor positions, Which Key, and window layout undo.
Do not persist the kill ring. All histories may contain private paths/input; delete =.local/= state
selectively when needed. Never sync this directory with notes.

=C--= and =C-+= (also =C-==) change the global font size in every buffer and
frame; =M--= remains available for a negative numeric argument. Leader maps are
ordinary keymaps, not a macro framework. =SPC= is the leader in
Evil normal/visual/motion states in every buffer, including package buffers
where Evil Collection binds =SPC= to a package command. =C-c SPC= remains
available in insert/Emacs states. =SPC m= resolves a buffer-local or registered
package menu, and =SPC ?= opens Which Key for the active mappings. Evil
Collection supplies j/k/h/l navigation in package buffers.

* Completion and visual styling

Vertico presents Emacs completion, Orderless matches words in any order,
Marginalia annotates candidates, and Consult supplies search and previews.
File completion keeps partial-completion for path handling. No Company/Corfu
overlap: Corfu below provides in-buffer completion over standard CAPFs.

=C-j= and =C-k= move down and up through Vertico, Corfu, built-in minibuffer
completion, and Transient menus; =RET= remains the accept key. They are not bound
globally, so ordinary editing keeps its normal behavior.

Vertico Posframe checks whether posframes work for the current display, so its
ordinary Vertico renderer remains available in terminal sessions. Do not gate
its loading solely on the first frame being graphical; daemon/mixed-frame
sessions must work too. This behavior still needs interactive display testing.

Consult's theme command already disables other themes and restores them when
aborted. Keep that implementation rather than writing custom preview advice.
Only trusted installed theme code should be previewed: themes execute Lisp.
Interactive theme selections last for the session; change =et/default-theme=
in this document (or machine settings) for a persistent default.

* Modeline

The modeline uses =doom-modeline= with Nerd Font icons, colors, version-control
state, diagnostics, LSP, position, and time. =minions= collapses the minor-mode
list so the bar stays readable. The icon font is installed explicitly with
=M-x et/install-nerd-fonts=; startup never downloads fonts. This is heavier than
=mood-line= or =nano-modeline= but keeps the information density and visual
polish of Doom. Set =doom-modeline-icon= to nil in =.local/settings.el= if the
terminal font lacks Nerd Font glyphs.

* Projects, workspaces, and in-buffer completion

Projectile supplies project recognition, files, search, and build/test commands.
Perspective supplies frame-local workspace buffer sets and layouts. They are
organizational tools, not sandboxes: explicitly opening any file can share it
between workspaces. =SPC b b= lists only current workspace buffers; =SPC b B=
is an intentional all-buffer escape hatch. Recent-file/bookmark sources are
not included in the scoped picker. Buffer cycling stays Perspective-aware.

Project workspace names include a hash of the full root, so two repositories
with the same basename do not collide. Project discovery is explicit; do not
recursively scan the user's home or remote hosts at startup. Use =SPC p a= to
register a project and =SPC p p= to switch. =SPC p w= associates the current
project with a workspace. Picking a file happens after switching workspaces.

Persistence is deliberately explicit: =SPC TAB S= saves and =SPC TAB L= restores
trusted local state. There is no automatic restore at startup or save on exit
that could overwrite a good session with an empty one. Only local file/Dired
buffers are persisted; terminals, servers, remote files, and tree buffers are
not restored. Workspace metadata such as project defaults can be re-established
with =SPC p w=. Do not enable desktop restoration over the same layouts.

The mode line's global notification area lists every workspace on the current
frame as a numbered tab, with the current workspace highlighted. =SPC TAB TAB=
opens the numbered list in Vertico and switches on selection; =SPC TAB 1= through
=SPC TAB 9= switch directly, and =SPC TAB 0= selects workspace ten. =SPC TAB l=
returns to the previous workspace, while =SPC TAB n=/=p= cycle in Perspective's
order.

Corfu is a trial, not a commitment: it displays Emacs completion-at-point
functions, including future Eglot results. Start with manual =C-M-i= completion
in editing buffers (and automatic completion after three characters). =TAB=
and =S-TAB= move; =RET= accepts only a selected candidate. Terminal Emacs uses
the built-in completion UI when Corfu child frames are unavailable. Cape and
Company are not installed without a specific missing completion source.

Treemacs has its own Perspective scope and Evil navigation. The tree is opened
on demand, not forced into every workspace. Pop-up rules use built-in
=display-buffer=, with help on the right and diagnostics/compilation below.

* Dashboard

The dashboard is a small =special-mode= buffer and the default startup buffer.
It reads Projectile's registered projects, =recentf-list=, up to five Personal
and five Work Org tasks, and Elfeed's cached articles without contacting the
network. Tasks are grouped by domain and sorted by state, explicit priority,
then deadline or schedule; overflow is shown as =+N more=. Buttons use Emacs's
built-in =button= library; article and task buttons open the browser or the
original Org heading. Refresh with =g=, quit with =q=, and use =RET= to activate a
button. =TAB= collapses or expands the news article list for the feed at point;
feed actions remain available. =SPC d= opens the dashboard; set
=et/dashboard-on-startup= to nil to start on scratch instead.

          (dolist (file files)
            (insert "  ")

             (abbreviate-file-name file)
             (lambda (_button) (find-file file))
             (format "Open %s" file))
            (insert "\n"))
        (insert "  No recent files yet.\n")))
    (insert "\n")
    (et/dashboard-insert-section "Agenda")

          any)

        (let ((domain (nth 0 group))
              (tasks (nth 1 group))
              (total (nth 2 group)))

* News and feeds

=elfeed= reads RSS. Scientific American has one public syndication feed; the
New York Times exposes separate topic feeds; Decipher, ArsTechnica Security,
TechNet/Microsoft Security, SecurityWeek, and BleepingComputer supply the
cybersecurity feeds. The Emacs site combines r/emacs, Planet Emacslife, Sacha
Chua's Emacs News, Mastering Emacs, System Crafters, and Emacs Stack Exchange;
toggle individual sources with =et/news-select-feeds=. All feeds are
downloaded, while =et/news-select-feeds= controls which topics contribute to the
dashboard's five newest articles per site. The dashboard reads only Elfeed's local cache, so startup never fetches the
network; =SPC N u= updates feeds. Each site's "Open full feed" button opens the
Elfeed search buffer filtered to that site. In an Elfeed search buffer,
=SPC N /= searches by keyword, =SPC N f= narrows to a feed, =SPC N d= narrows to a
date range, =SPC N m=/=M= mark read/unread, and =SPC N r= creates an Org-roam
reference note with an AI-summary placeholder (extension hook:
=et/news-roam-ai-hook=). =S= in the dashboard or =SPC N r= / =SPC N R= /
=SPC N S= in Elfeed downloads the article and opens an unsaved AI summary
draft. In the draft, =C-c= accepts and saves, =C-k= cancels, =C-r=
regenerates with the current model, and =C-m= chooses another gptel model.
The prompt first classifies the article: cybersecurity articles get the full
=* Security details= structure, while other articles contain only metadata and
=* Summary=, with no security section or forced security tag. Summary tags use
=_= as the only separator and carry category prefixes: =#= topics, =@=
people/groups/foundations, =$= companies, and =!= MITRE techniques. Org's tag
syntax is extended locally to allow =$= and =!=.

                               (re-search-forward "\r?\n\r?\n" nil t))

                                   (point) (point-max))))
                        (if (string-match-p "<\\(?:html\\|article\\|body\\)"
                                            body)
                            (et/news--html-to-text body)
                          (string-trim body))))))
              (kill-buffer buffer)))))
    (error nil)))

(defun et/news--fetch-article-text-curl (url)
  "Download URL with curl, or return nil when curl is unavailable."
  (when (executable-find "curl")

      (when (eq 0
                (call-process "curl" nil t nil
                              "-L" "--compressed" "--max-time" "20"
                              "-s" "-A" et/news-user-agent
                              "-H" "Accept: text/html,application/xhtml+xml,text/plain"
                              url))
        (let ((body (buffer-string)))
          (when (not (string-blank-p body))
            (if (string-match-p "<\\(?:html\\|article\\|body\\)" body)
                (et/news--html-to-text body)
              (string-trim body))))))))

(defun et/news--clean-tag (tag)
  "Return TAG as a prefixed Org tag using `_' as the only separator."
  (let* ((tag (string-trim (or tag "")))
         (mitre (and (string-match
                      "\\`\\(?:#\\|!\\)?\\([Tt][0-9]+\\(?:[._][0-9]+\\)?\\)\\'"
                      tag)
                     (upcase (replace-regexp-in-string
                              "[._]" "_" (match-string 1 tag))))))
    (cond
     ((string-empty-p tag) nil)
     (mitre (concat "!" mitre))
     (t
      (let* ((lower (downcase tag))
             (prefix (if (memq (aref lower 0) '(?@ ?# ?$ ?!))
                         (substring lower 0 1)
                       "#"))
             (body (if (memq (aref lower 0) '(?@ ?# ?$ ?!))
                       (substring lower 1)
                     lower)))
        (setq body (replace-regexp-in-string "[^[:alnum:]_]" "_" body))
        (setq body (replace-regexp-in-string "_+" "_" body))
        (setq body (string-trim body "_"))
        (unless (string-empty-p body)
          (concat prefix body)))))))

(defun et/news--clean-cell (value)
  "Return VALUE as a single-line table cell."
  (replace-regexp-in-string
   "[|\n\r]+" " " (string-trim (or value ""))))

(defun et/news--parse-summary-output (output)
  "Parse OUTPUT into tags, ecosystem, description, body, and related rows."
  (let* ((output (string-trim output))
         (output (replace-regexp-in-string
                  "\\`[ \t]*```\\(?:org\\)?[ \t]*\n" "" output))
         (output (replace-regexp-in-string
                  "\n?[ \t]*```[ \t]*\\'" "" output))
         (body-start (or (string-match "^\\* Summary" output) 0))
         (metadata (substring output 0 body-start))
         (body (substring output body-start))
         ecosystem description tags related)
    (when (string-match "^#\\+ecosystem:[ \t]*\\(.*\\)$" metadata)
      (setq ecosystem (string-trim (match-string 1 metadata))))
    (when (string-match "^#\\+description:[ \t]*\\(.*\\)$" metadata)
      (setq description (string-trim (match-string 1 metadata))))
    (when (string-match "^#\\+filetags:[ \t]*\\(.*\\)$" metadata)
      (setq tags (delq nil (mapcar #'et/news--clean-tag
                                   (split-string (match-string 1 metadata)
                                                 ":" t)))))
    (with-temp-buffer
      (insert body)
      (org-mode)
      (goto-char (point-min))
      (when (re-search-forward "^\\*\\* Related nodes\\b" nil t)
        (forward-line 1)
        (when (org-at-table-p)
          (dolist (row (cdr (org-table-to-lisp)))
            (unless (eq row 'hline)
              (let ((type (et/news--clean-cell (nth 0 row)))
                    (title (et/news--clean-cell (nth 1 row)))
                    (relationship (et/news--clean-cell (nth 2 row)))
                    (why (et/news--clean-cell (nth 3 row))))
                (unless (string-empty-p title)
                  (push (list :type type :title title
                              :relationship relationship :why why)
                        related))))))))
    (list :tags tags
          :ecosystem ecosystem
          :description description
          :body body
          :related (nreverse related))))

    (replace-regexp-in-string "\\s-+" " " title)))

(defun et/news--find-or-create-related-node (type title)
  "Return the Org-roam node for TITLE, creating a typed stub if needed."
  (let* ((title (et/news--clean-node-title title))
         (type (downcase (or type "related")))
         (tag (pcase type
                ("language" "language")
                ("platform" "platform")
                ("package-manager" "package-manager")
                ("product" "product")
                ("vendor" "vendor")
                ("malware" "malware")
                ("campaign" "campaign")
                (_ "related"))))
    (when (string-empty-p title)
      (user-error "Empty related-node title"))
    (or (et/news--node-by-title title)
        (let* ((slug (org-roam-node-slugify title))
               (file (expand-file-name
                      (concat et/news-related-node-domain "/topics/" slug ".org")
                      et/roam-directory)))
          (if (file-exists-p file)
              (with-current-buffer (find-file-noselect file)
                (goto-char (point-min))
                (if (re-search-forward "^:ID:[ \t]+\\([^ \t\n]+\\)" nil t)
                    (or (org-roam-node-from-id (match-string 1))
                        (progn
                          (org-roam-db-update-file file)
                          (org-roam-node-from-id (match-string 1))))
                  (user-error "Existing related note has no ID: %s" file)))
            (let ((id (org-id-new)))
              (make-directory (file-name-directory file) t)
              (with-current-buffer (find-file-noselect file)
                (insert ":PROPERTIES:\n")
                (insert (format ":ID: %s\n" id))
                (insert ":END:\n")
                (insert (format "#+title: %s\n" title))
                (insert (format "#+filetags: :%s:\n\n" tag))
                (insert "* Related articles\n")
                (org-mode)
                (save-buffer)
                (when (fboundp 'org-roam-db-update-file)
                  (org-roam-db-update-file file)))
              (or (org-roam-node-from-id id)
                  (user-error "Created node is not indexed: %s" title))))))))

(defun et/news--link-related-table (rows)
  "Replace the Related nodes table with linked ROWS."
  (goto-char (point-min))
  (when (re-search-forward "^\\*\\* Related nodes\\b" nil t)
    (forward-line 1)
    (if (org-at-table-p)
        (let ((beg (org-table-begin))
              (end (org-table-end)))
          (delete-region beg end)
          (goto-char beg)
          (insert "| Type | Node title | Relationship | Why |\n")
          (insert "|------+------------+--------------+-----|\n")
          (dolist (row rows)
            (insert (format "| %s | [[id:%s][%s]] | %s | %s |\n"
                            (et/news--clean-cell (plist-get row :type))
                            (plist-get row :id)
                            (et/news--clean-cell (plist-get row :title))
                            (et/news--clean-cell (plist-get row :relationship))
                            (et/news--clean-cell (plist-get row :why))))
          (org-table-align))
      (end-of-line)
      (insert "\n")
      (dolist (row rows)
        (insert (format "- [[id:%s][%s]] - %s\n"
                        (plist-get row :id)
                        (et/news--clean-cell (plist-get row :title))
                        (et/news--clean-cell (plist-get row :relationship)))))))))

(defun et/news--append-related-article (node summary-id summary-title date why)
  "Append a backlink to NODE for the summary article."
  (when (and node (org-roam-node-file node)
             (not (equal (org-roam-node-id node) summary-id)))
    (let ((file (org-roam-node-file node)))
      (with-current-buffer (find-file-noselect file)
        (unless (derived-mode-p 'org-mode) (org-mode))
        (save-excursion
          (goto-char (point-min))
          (unless (search-forward summary-id nil t)
            (goto-char (point-max))
            (unless (bolp) (insert "\n"))
            (if (re-search-backward "^\\* Related articles[ \t]*$" nil t)
                (progn
                  (forward-line 1)
                  (let ((end (save-excursion
                               (when (re-search-forward "^\\* " nil t)
                                 (line-beginning-position)))))
                    (goto-char (or end (point-max)))
                    (unless (bolp) (insert "\n"))))
              (goto-char (point-max))
              (unless (bolp) (insert "\n"))
              (insert "* Related articles\n"))
            (insert (format "- [[id:%s][%s]] - %s%s\n"
                            summary-id
                            (et/news--clean-cell summary-title)
                            date
                            (if (and why (not (string-empty-p why)))
                                (concat " - " (et/news--clean-cell why))
                              "")))))
        (save-buffer)
        (when (fboundp 'org-roam-db-update-file)
          (org-roam-db-update-file file))))))

(defun et/news--create-summary-note (output context)
  "Create an article summary note from OUTPUT and CONTEXT."
  (et/news--ensure-roam-db)
  (let* ((parsed (et/news--parse-summary-output output))
         (title (replace-regexp-in-string
                 "[\r\n]+" " "
                 (or (plist-get context :title) "Untitled article")))
         (link (or (plist-get context :link) ""))
         (feed (replace-regexp-in-string
                "[\r\n]+" " " (or (plist-get context :feed) "News")))
         (published (or (plist-get context :date)
                        (format-time-string "%Y-%m-%d")))
         (domain (or (plist-get context :domain) (et/current-domain)))
         (tags (delete-dups
                (append '("news" "reference")
                        (plist-get parsed :tags))))
         (ecosystem (plist-get parsed :ecosystem))
         (description (plist-get parsed :description))
         (body (plist-get parsed :body))
         (related (plist-get parsed :related))
         (slug (org-roam-node-slugify title))
         (file (expand-file-name
                (concat domain "/references/"
                        (format-time-string "%Y%m%d%H%M%S") "-" slug ".org")
                et/roam-directory))
         (id (org-id-new)))
    (unless (and body (string-match-p "^\\* Summary" body))
      (user-error "AI response did not contain a Summary section"))
    (make-directory (file-name-directory file) t)
    (with-current-buffer (find-file-noselect file)
      (insert ":PROPERTIES:\n")
      (insert (format ":ID: %s\n" id))
      (insert (format ":ROAM_REFS: %s\n" link))
      (insert (format ":SOURCE: %s\n" link))
      (insert (format ":FEED: %s\n" feed))
      (insert (format ":PUBLISHED: %s\n" published))
      (insert (format ":CAPTURED: %s\n" (format-time-string "%Y-%m-%d")))
      (when (and ecosystem (not (string-empty-p ecosystem)))
        (insert (format ":ECOSYSTEM: %s\n" ecosystem)))
      (insert ":END:\n")
      (insert (format "#+title: %s\n" title))
      (insert (format "#+filetags: :%s:\n" (mapconcat #'identity tags ":")))
      (when (and ecosystem (not (string-empty-p ecosystem)))
        (insert (format "#+ecosystem: %s\n" ecosystem)))
      (when (and description (not (string-empty-p description)))
        (insert (format "#+description: %s\n" description)))
      (insert "\n")
      (insert body)
      (unless (bolp) (insert "\n"))
      (org-mode)
      (let ((nodes
             (delq nil
                   (mapcar
                    (lambda (row)
                      (let* ((type (plist-get row :type))
                             (node-title (plist-get row :title))
                             (node (et/news--find-or-create-related-node
                                    type node-title)))
                        (when node
                          (plist-put row :id (org-roam-node-id node))
                          row)))
                    related))))
        (when nodes (et/news--link-related-table nodes))
        (save-buffer)
        (when (fboundp 'org-roam-db-update-file)
          (org-roam-db-update-file file))
        (dolist (row nodes)
          (when-let* ((node-id (plist-get row :id))
                      (node (org-roam-node-from-id node-id)))
            (et/news--append-related-article
             node id title (format-time-string "%Y-%m-%d")
             (plist-get row :why))))
        (save-buffer)
        (when (fboundp 'org-roam-db-update-file)
          (org-roam-db-update-file file))))
    (find-file file)
    (message "Created article summary: %s" title)))

* Following links

=RET= in Evil normal state follows the thing at point instead of only moving by
line: dashboard buttons, Org links (including plain URLs), web URLs in any
buffer, and =file:=, =id:=, or =roam:= links embedded in non-Org text. Insert
state keeps its ordinary newline behavior; when there is nothing to follow the
command falls back to =evil-ret= (or =newline= outside Evil). The generic path
uses =browse-url= for web links and =org-link-open-from-string= for Org-style
links, so Markdown, code comments, and other text can carry usable links.

#+begin_src emacs-lisp :tangle lisp/et-links.el

(require 'button)
(require 'subr-x)

(defvar et/link-regexp
  "\\(?:https?\\|file\\|id\\|roam\\):[^][()<> \t\n]+"
  "Link-like text recognized outside Org buffers.")

(defun et/link-at-point ()
  "Return the URL or generic link at point, or nil."
  (or (when-let* ((url (thing-at-point 'url t)))
        (string-trim url "[[:space:]]+\\|[.,;:]+\\'"))
      (let ((at (point)))
        (save-excursion
          (goto-char (line-beginning-position))
          (when (re-search-forward et/link-regexp (line-end-position) t)
            (let ((start (match-beginning 0))
                  (end (match-end 0)))
              (when (and (<= start at) (<= at end))
                (buffer-substring-no-properties start end))))))))

(defun et/org-bracket-link-at-point ()
  "Return the target of an Org bracket link around point, or nil."
  (let ((at (point)))
    (save-excursion
      (goto-char (line-beginning-position))
      (when (re-search-forward
             "\\[\\[\\([^]]+\\)\\]\\(?:\\[\\([^]]*\\)\\]\\)?\\]"
             (line-end-position) t)
        (let ((start (match-beginning 0))
              (link-end (match-end 0))
              (target (match-string 1)))
          (when (and (<= start at) (<= at link-end))
            target))))))

  "Return the URL of a Markdown inline link around point, or nil."
  (let ((at (point)))
    (save-excursion
      (goto-char (line-beginning-position))
      (when (re-search-forward
             "\\[[^]]*\\](\\([^)]+\\))" (line-end-position) t)
        (let ((start (match-beginning 0))
              (link-end (match-end 0))
              (url (match-string 1)))
          (when (and (<= start at) (<= at link-end))
            url))))))

* AI assistance

=gptel= talks to OpenAI, Anthropic, and DeepSeek. API keys are never stored in
this repository: the backends first look up the provider's normal API host with
the auth-source user =emacs=, so =~/.authinfo.gpg= remains the source of truth.
Only when no matching entry exists does Emacs prompt for a different machine and
user. The global default model is =gpt-6-luna= on OpenAI. =SPC a w= rewrites the
active region with a model selected from gptel's provider/model completion;
choose either a one-off model or set it as the persistent default. The default
is saved in =.local/gptel.el= and reloaded at startup. Reasoning text is hidden
by default because providers bill reasoning tokens as output; =SPC a r= toggles
it deliberately for one session. Article summaries use a dedicated OpenAI
backend with =gpt-6-luna=; change =et/news-summary-model= to use another model.
That summary model is independent of both project defaults and the project-level
=opencode.json=, which sets OpenCode's default to =deepseek/deepseek-flash= for
this branch.

The first AI command in a project asks for both an OpenCode model and a gptel
model. Choices are stored in =.local/project-models.el= (mode 0600) by canonical
project root. The OpenCode choice is also written to the project's root
=opencode.json= =model= key, preserving any other settings; a JSONC file or a
JSON file containing comments is left unchanged. Cancelling either prompt
leaves that half unset so the next AI use asks again. Remote projects are not
prompted. In project buffers, gptel uses the saved project model;
=SPC a l= changes only the OpenCode project model, and =SPC p m= reconfigures
both.

Both model selectors support favorites. Press =C-f= on the highlighted model to
add or remove it; favorites are saved in =.local/model-favorites.el= (mode 0600)
and are sorted first under a =★ Favorites= group heading, which Vertico renders
as a separator line above all other models. =C-f= is bound only while one of
these selectors is open, so ordinary minibuffer behavior is unchanged.

Saved OpenCode sessions are project bookmarks with a local context export.
=SPC S s= (or =SPC m S= inside a session) saves the current session to
=.local/opencode-sessions.el= and exports its complete transcript with
=opencode session export= to =.local/opencode-sessions/<id>.json= (mode 0600).
=SPC S l= selects a saved session for the current project and reopens it after
a restart; outside a project it prompts for one of the saved project roots.
=SPC S o= opens the live OpenCode project-session picker, and =SPC S d= removes
a bookmark while keeping its exported context. Emacs layouts and files remain
separate: use =SPC TAB S= / =SPC TAB L= for those.

=emacs-opencode= adds an OpenCode 2 client in native Emacs buffers. It is not
published on MELPA, so =et/install-packages= clones it from GitHub with
=package-vc=. Its HTTP client dependency =request= comes from MELPA and is
listed explicitly because the repository does not declare it. The client needs
the =opencode= CLI and =curl= on =PATH=; it reuses OpenCode's shared background
service and starts it on demand. Opening a session does not send anything until
a prompt is submitted. =SPC a o= starts a new session, =SPC a O= reopens an
existing one, =SPC a a= asks a one-shot question, and =SPC a c= sends the active
region (or the lines around point) along with the prompt. Sessions use the saved
project model; if it is no longer available, the session prompts for a
replacement. Connected providers with an API key or subscription credential
appear before free/local providers and providers that still need connecting. In
an OpenCode session buffer, use =SPC m l= to switch that session only,
=SPC a l= to change the project default and current session together, =SPC m a=
for the agent, and =SPC m v= for the model variant. When Magit is available, the
optional =emacs-opencode-magit= integration adds repository diffs under
=C-c C-d= in session buffers.

  "Toggle MODEL as a favorite of KIND.

  (let* ((current (et/model-favorite-list kind))
         (favorite (member model current))
         (updated (if favorite
                      (cl-remove model current :test #'equal)

(defun et/model--ordered (kind choices group-function)
  "Return (ORDERED . GROUP-FUNCTION) with KIND favorites first.
CHOICES is the original candidate list.  GROUP-FUNCTION labels the
non-favorite candidates."
  (let* ((favorites (seq-filter (lambda (choice)
                                  (et/model-favorite-p kind choice))
                                choices))
         (others (seq-remove (lambda (choice)
                               (et/model-favorite-p kind choice))
                             choices)))
    (cons (append favorites others)
          (lambda (candidate transform)
            (cond
             ((et/model-favorite-p kind candidate)
              (if transform candidate "★ Favorites"))
             (group-function
              (funcall group-function candidate transform))
             (t (if transform candidate "")))))))

                  (boundp 'vertico--index)
                  (integerp vertico--index)
                  (>= vertico--index 0))
             (vertico--candidate)
           (minibuffer-contents-no-properties))))
    (and (stringp candidate) (substring-no-properties candidate))))

     ((not (and candidate (member candidate choices)))
      (message "Point is not on a model"))

  (lambda ()

(defun et/model--read (prompt choices kind &optional default
                              group-function annotation-function
                              favoritable-p)
  "Read a model from CHOICES with KIND favorites first.
PROMPT is the completion prompt.  GROUP-FUNCTION and ANNOTATION-FUNCTION
are passed to completion.  FAVORITABLE-P limits favorite-toggle targets.
Return the selected model string, or nil when cancelled."
  (let (selection retry)
    (while (progn
             (setq retry nil)
             (let* ((ordered-info (et/model--ordered kind choices group-function))
                    (ordered (car ordered-info))
                    (group-fn (cdr ordered-info))
                    (completion-extra-properties
                     `(:display-sort-function identity
                       :cycle-sort-function identity
                       :group-function ,group-fn
                       ,@(when annotation-function
                           `(:annotation-function ,annotation-function)))))
               (let ((result
                      (catch 'et/model--favorite-toggled
                        (setq selection
                              (let ((minibuffer-setup-hook
                                     (append minibuffer-setup-hook
                                             (list
                                              (et/model--favorite-setup
                                               kind choices favoritable-p)))))
                                (completing-read
                                 prompt ordered nil t nil nil
                                 (or default (car ordered))))))))
                 (when (and (consp result) (eq (car result) :retry))
                   (setq default (cdr result)
                         retry t))))
             retry))
    selection))

(defun et/opencode--read-project-model (root)
  "Read ROOT's OpenCode model from the CLI catalog."
  (let* ((models (et/opencode--cli-models root))
         (configured (or (et/project-model-get root :opencode)
                         (et/project--opencode-config-model root)))
         (default (if (member configured models) configured (car models))))
    (unless models
      (user-error "OpenCode models are not available"))
    (et/model--read
     (format "OpenCode model for %s: "
             (file-name-nondirectory
              (directory-file-name (et/project--canonical-root root))))
     models 'opencode default
     (lambda (candidate transform)
       (if transform
           candidate
         (et/opencode--display-provider candidate))))))

(defun et/project--write-opencode-model (root model)
  "Write MODEL to ROOT's opencode.json, preserving other settings."
  (condition-case err
      (let* ((root (et/project--canonical-root root))
             (file (expand-file-name "opencode.json" root))
             (config
              (cond
               ((not (file-exists-p file)) nil)
               (t (condition-case nil
                      (with-temp-buffer
                        (insert-file-contents file)
                        (goto-char (point-min))
                        (json-parse-buffer :object-type 'alist))
                    (error :invalid))))))
        (if (eq config :invalid)
            (progn
              (message "Leaving unreadable OpenCode config unchanged: %s" file)
              nil)
          (let ((config (copy-sequence config)))
            (setf (alist-get 'model config) model)
            (unless (assoc '$schema config)
              (push '($schema . "https://opencode.ai/config.json") config))
            (let ((temp (make-temp-file
                         (expand-file-name ".opencode-" root) nil ".json")))
              (unwind-protect
                  (progn
                    (with-temp-file temp
                      (insert (json-serialize config))
                      (json-pretty-print (point-min) (point-max))
                      (insert "\n"))
                    (rename-file temp file t)
                    (set-file-modes file #o644))
                (when (file-exists-p temp)
                  (delete-file temp))))
            t)))
    (error
     (message "Could not update OpenCode config: %s"
              (error-message-string err))
     nil)))

(defun et/gptel-backend-by-name (name)
  "Return the gptel backend named NAME."
  (or (cdr (assoc name gptel--known-backends))
      (seq-find (lambda (backend)
                  (and backend
                       (equal (gptel-backend-name backend) name)))
                (list et/gptel-openai et/gptel-anthropic et/gptel-deepseek))
      et/gptel-openai))

(defun et/project-gptel-choice (root)
  "Return ROOT's stored gptel choice as (BACKEND . MODEL), when valid."
  (when-let* ((root (et/project--canonical-root root))
              (stored (et/project-model-get root :gptel))
              (name (car-safe stored))
              (model (cdr-safe stored)))
    (let ((backend (et/gptel-backend-by-name name)))
      (when (and backend model
                 (memq model (gptel-backend-models backend)))
        (cons backend model)))))

(defun et/project-apply-gptel-model (&optional root)
  "Apply ROOT's project gptel model in the current buffer."
  (when (locate-library "gptel")
    (require 'gptel)
    (let* ((root (or (et/project--canonical-root root)
                     (ignore-errors
                       (et/project--canonical-root
                        (projectile-project-root)))))
           (choice (and root (et/project-gptel-choice root))))
      (when choice
        (setq-local gptel-backend (car choice)
                    gptel-model (cdr choice))))))

(defun et/gptel-default-display ()
  "Return the default gptel model display for the current project."
  (let* ((root (ignore-errors
                 (et/project--canonical-root (projectile-project-root))))
         (choice (and root (et/project-gptel-choice root)))
         (backend (or (car-safe choice) gptel-backend))
         (model (or (cdr-safe choice) gptel-model)))

(defun et/project-ensure-models (&optional root)
  "Ensure ROOT has OpenCode and gptel models, prompting once."
  (let ((root (et/project--canonical-root
               (or root
                   (ignore-errors (projectile-project-root))))))
    (when (and root
               (not (file-remote-p root))
               (not (et/project-models-configured-p root)))
      (unless (et/project-model-get root :opencode)
        (if (executable-find "opencode")
            (condition-case err
                (et/project-configure-opencode-model root)
              (quit nil)
              (user-error
               (message "%s" (error-message-string err))))
          (message "OpenCode CLI not found; skipping project OpenCode model")))
      (unless (et/project-model-get root :gptel)
        (if (locate-library "gptel")
            (condition-case err
                (et/project-configure-gptel-model root)
              (quit nil)
              (user-error
               (message "%s" (error-message-string err))))
          (message "gptel not installed; skipping project gptel model")))
      (et/project-apply-gptel-model root))
    root))

(defun et/opencode-session--record (session root)
  "Return a bookmark record for SESSION in ROOT."
  (let* ((info (or (opencode-session-info session) '()))
         (model-info (alist-get 'model info))
         (id (opencode-session-id session))
         (title (or (opencode-session-title session) "Untitled session"))
         (provider (or (bound-and-true-p opencode-session--provider-id)
                       (alist-get 'providerID model-info)))
         (model (or (bound-and-true-p opencode-session--model-id)
                    (alist-get 'id model-info)))
         (agent (or (bound-and-true-p opencode-session--agent)
                    (alist-get 'agent info)))
         (directory (or (opencode-session-directory session) root)))
    (list :id id
          :title title
          :saved (format-time-string "%Y-%m-%d %H:%M:%S")
          :directory directory
          :provider provider
          :model model
          :agent agent
          :export (expand-file-name
                   (concat (replace-regexp-in-string
                            "[^[:alnum:]_.-]" "_" (or id "session"))
                           ".json")
                   et/opencode-sessions-directory))))

(defun et/opencode-session--export (record)
  "Export RECORD's session context to its JSON file."
  (condition-case err
      (let ((id (plist-get record :id))
            (directory (plist-get record :directory))
            (file (plist-get record :export)))
        (when (and (executable-find "opencode")
                   (stringp id)
                   (stringp directory)
                   (not (file-remote-p directory)))
          (make-directory (file-name-directory file) t)
          (let ((default-directory (file-name-as-directory directory))
                (coding-system-for-write 'utf-8-unix))
            (with-temp-buffer
              (let ((status (call-process
                             "opencode" nil t nil
                             "session" "export" id)))
                (when (and (integerp status) (zerop status)
                           (> (buffer-size) 0))
                  (write-region (point-min) (point-max) file nil 'silent)
                  (set-file-modes file #o600)
                  t))))))
    (error
     (message "OpenCode context export failed: %s"
              (error-message-string err))
     nil)))

(defun et/opencode-session-save ()
  "Save the current OpenCode session bookmark and export its context."
  (interactive)
  (let ((session (et/opencode-session--buffer-session)))
    (unless session
      (user-error "Open an OpenCode session buffer first"))
    (let* ((root (or (et/opencode-session--root)
                     (et/project--canonical-root default-directory)))
           (record (et/opencode-session--record session root)))

      (message "Exporting OpenCode session context...")
      (if (et/opencode-session--export record)
          (message "Saved OpenCode session and context: %s"
                   (plist-get record :title))

                 (plist-get record :title)))

(defvar et/gptel-state-file
  (expand-file-name "gptel.el" et/state-directory)
  "Persistent gptel default backend and model.")

(defun et/gptel-select-model ()
  "Select a gptel model, returning (BACKEND . MODEL)."
  (require 'gptel)
  (let (models-alist choices)
    (dolist (entry gptel--known-backends)
      (let ((name (car entry))
            (backend (cdr entry)))
        (dolist (model (gptel-backend-models backend))
          (push (list (concat name ":" (gptel--model-name model))
                      backend model)
                models-alist))))
    (setq models-alist (nreverse models-alist)
          choices (mapcar #'car models-alist))
    (let* ((group-function
            (lambda (cand transform)
              (if transform
                  cand
                (gptel-backend-name (nth 1 (assoc cand models-alist))))))
           (annotation-function
            (lambda (comp)
              (let* ((model (nth 2 (assoc comp models-alist)))
                     (desc (get model :description)))
                (when desc
                  (concat " "
                          (truncate-string-to-width desc 70 nil ?  t t))))))
           (choice (et/model--read
                    "Model: " choices 'gptel
                    (et/gptel-default-display)
                    group-function annotation-function))
           (entry (assoc choice models-alist)))
      (when entry
        (cons (nth 1 entry) (nth 2 entry))))))

(defun et/gptel-save-default (backend model)
  "Persist BACKEND and MODEL as the default gptel choice."
  (let ((coding-system-for-write 'utf-8-unix))
    (with-temp-file et/gptel-state-file
      (insert ";; Generated by et/gptel-set-default; do not edit by hand.\n")
      (prin1 (list (cons 'backend (gptel-backend-name backend))
                   (cons 'model model))
             (current-buffer))
      (insert "\n")))
  (set-file-modes et/gptel-state-file #o600))

(defun et/gptel-load-default ()
  "Load the persisted gptel backend and model, when valid."
  (when (file-readable-p et/gptel-state-file)
    (condition-case nil
        (with-temp-buffer
          (insert-file-contents et/gptel-state-file)
          (goto-char (point-min))
          (let* ((state (read (current-buffer)))
                 (name (cdr (assq 'backend state)))
                 (model (cdr (assq 'model state)))
                 (backend (or (cdr (assoc name gptel--known-backends))
                              et/gptel-openai)))
            (when (and backend model
                       (memq model (gptel-backend-models backend)))
              (setq gptel-backend backend
                    gptel-model model))))
      (error nil))))

(defun et/gptel-set-default (&optional backend model)
  "Set BACKEND and MODEL as the persistent gptel default."
  (interactive
   (let ((choice (et/gptel-select-model)))
     (when choice
       (list (car choice) (cdr choice)))))
  (unless (and backend model)
    (user-error "No model selected"))
  (setq gptel-backend backend
        gptel-model model)
  (et/gptel-save-default backend model)
  (message "Default gptel model: %s / %s"
           (gptel-backend-name backend)
           (gptel--model-name model)))

;; OpenCode's built-in model picker prioritizes recent and connected models.
;; Etmacs additionally puts providers with a stored API key or subscription
;; credential before free/local providers and connectable providers.
(defun et/opencode--provider-credential-p (connection provider-id)
  "Whether PROVIDER-ID has an API-key/OAuth credential on CONNECTION."
  (when-let* ((integration
               (opencode-session--find-integration connection provider-id)))
    (seq-some
     (lambda (item)
       (let ((method (alist-get 'method item)))
         (or (member method '("key" "oauth" "env"))
             (equal (alist-get 'type item) "credential"))))
     (opencode-session--normalize-items (alist-get 'connections integration)))))

(defun et/opencode--candidate-group (candidate connection)
  "Return CANDIDATE's ordering group on CONNECTION.
Groups are paid, free/local, or connectable."
  (cond
   ((not (plist-get candidate :connected-p)) 2)
   ((et/opencode--provider-credential-p
     connection (plist-get candidate :provider-id))
    0)
   (t 1)))

(defun et/opencode--candidate-group-label (candidate connection)
  "Return a completion group label for CANDIDATE on CONNECTION."
  (pcase (et/opencode--candidate-group candidate connection)
    (0 "Paid subscription / API key")
    (1 "Free / local")
    (_ "Connect a provider")))

(defun et/opencode--candidate-alpha< (a b)
  "Return non-nil when CANDIDATE A sorts before CANDIDATE B by name."
  (let ((a-provider (downcase (or (plist-get a :provider-name) "")))
        (b-provider (downcase (or (plist-get b :provider-name) "")))
        (a-model (downcase (or (plist-get a :model-name) "")))
        (b-model (downcase (or (plist-get b :model-name) ""))))
    (if (string= a-provider b-provider)
        (string-lessp a-model b-model)
      (string-lessp a-provider b-provider))))

(defun et/opencode--sort-model-candidates (candidates connection)
  "Sort CANDIDATES so paid models are first on CONNECTION.
Within each group, recently used and session-used models stay first."
  (let ((recent opencode-session--recent-models)
        (session (ignore-errors (opencode-session--session-used-models))))
    (sort (copy-sequence candidates)
          (lambda (a b)
            (let* ((a-group (et/opencode--candidate-group a connection))
                   (b-group (et/opencode--candidate-group b connection))
                   (a-tier (if (plist-get a :connected-p)
                               (opencode-session--model-candidate-tier
                                a recent session)
                             3))
                   (b-tier (if (plist-get b :connected-p)
                               (opencode-session--model-candidate-tier
                                b recent session)
                             3))
                   (a-rank (if (<= a-tier 1)
                               (opencode-session--model-candidate-rank
                                a a-tier (if (= a-tier 0) recent session))
                             0))
                   (b-rank (if (<= b-tier 1)
                               (opencode-session--model-candidate-rank
                                b b-tier (if (= b-tier 0) recent session))
                             0)))
              (cond
               ((/= a-group b-group) (< a-group b-group))
               ((/= a-tier b-tier) (< a-tier b-tier))
               ((<= a-tier 1) (< a-rank b-rank))
               (t (et/opencode--candidate-alpha< a b))))))))

(defun et/opencode--sorted-candidates (orig &optional connection)
  "Return ORIG's model candidates sorted with paid models first.
CONNECTION defaults to the current session buffer's connection."
  (et/opencode--sort-model-candidates
   (funcall orig connection)
   (or connection opencode-session--connection)))

(defun et/opencode--read-model (connection &optional provider-id)
  "Read a model for CONNECTION, optionally limited to PROVIDER-ID.
Returns the selected candidate plist, or nil when the prompt is cancelled."
  (let* ((candidates
          (et/opencode--sort-model-candidates
           (opencode-session--provider-model-candidates connection)
           connection))
         (lookup (make-hash-table :test #'equal))
         choices)
    (dolist (candidate candidates)
      (let ((display (plist-get candidate :display)))
        (when (and (stringp display)
                   (or (null provider-id)
                       (and (plist-get candidate :connected-p)
                            (equal (plist-get candidate :provider-id)
                                   provider-id)))
                   (not (gethash display lookup)))
          (push display choices)
          (puthash display candidate lookup))))
    (setq choices (nreverse choices))
    (unless choices
      (user-error "OpenCode models are not available"))
    (let* ((group-function
            (lambda (candidate transform)
              (if transform
                  candidate
                (let ((entry (gethash candidate lookup)))
                  (if entry
                      (et/opencode--candidate-group-label entry connection)
                    "")))))
           (annotation-function
            (lambda (candidate)
              (let ((entry (gethash candidate lookup)))
                (when (and entry
                           (= (et/opencode--candidate-group entry connection) 0))
                  "  [paid]"))))
           (selection
            (et/model--read
             (if provider-id
                 (format "OpenCode %s model: " provider-id)
               "OpenCode model: ")
             choices 'opencode (car choices)
             group-function annotation-function
             (lambda (candidate)
               (let ((entry (gethash candidate lookup)))
                 (and entry (plist-get entry :connected-p)))))))
      (gethash selection lookup))))

* Terminal: vterm

=vterm= provides a real terminal through libvterm. It needs an Emacs built with
dynamic modules and the compiled =vterm-module.so=; the first launch may build
the module with =cmake=, =make=, and a C compiler, or you can install your
distribution's libvterm and compile it yourself. Nothing terminal-related starts
at boot: the shell starts only when you ask for it.

=SPC o t= toggles a persistent popup at the bottom of the frame in the current
workspace, using the project root as its directory. With a prefix argument it
recreates the buffer at that root. =SPC o T= opens a terminal in the current
window instead. Both export the project root as =PROOT=. For Tramp buffers, the
new terminal connects to the remote host with the method's login program and
changes to the remote directory. The module follows Doom's terminal defaults:
exit kills the buffer, scrollback holds 5000 lines, the modeline is hidden,
killing it does not ask about running processes, and horizontal scrolling is
disabled.

* Prelude-inspired editing and navigation

This layer adopts capabilities from [[https://github.com/bbatsov/prelude][Emacs Prelude]], not its startup framework or
global keymap. Existing Evil/leader keys, package installation policy, workspace
boundaries, Corfu/Vertico, and the theme remain ours. No Prelude dependency.

** Built-in defaults first

EditorConfig honors project indentation conventions instead of forcing spaces
on every language. Use eight-column tab display (not eight-column indentation).
Delete-selection, duplicate kill suppression, clipboard preservation, search
counts, readable duplicate buffer names, current-line/paren highlighting, and
compilation colors need no packages. Smooth pixel scrolling is built in too.

Local, unmodified file buffers track external changes; remote auto-revert is
disabled. Recent files live in our state directory, excluding remote paths,
encrypted/auth files, and our internal state. Recent-file lookup is an explicit
global navigation command (=SPC f r=), not part of scoped buffer switching.

We do NOT enable super-save, midnight buffer cleanup, persisted kill rings,
global whitespace cleanup, automatic pasted-text indentation, global formatting,
or automatic chmod. Recursive Dired operations still ask at the top level.
Compile keeps its save prompt and does not automatically kill an existing job.

** Navigation and editing helpers

- =avy= jumps to visible text; =ace-window= selects visible windows in the
  current frame. They do not enumerate hidden buffers from other workspaces.
- =expand-region= grows/shrinks a semantic selection, complementing Evil text
  objects. It does not create a second modal editing system.
- =crux= supplies selected explicit commands (open line, duplicate, rename).
  We don't install its broad global remappings or advice for automatic edits.
- =smartparens= is no longer used. Lisp buffers get =parinfer-rust-mode= for
  structural editing and =rainbow-delimiters= for depth readability. Other
  programming modes keep built-in electric-pair. No competing Parinfer/Paredit

* Org planning and capture

Built-in Org owns tasks, capture, refile, habits, clocks, Babel, IDs, and export.
Task files are =~/org/{personal,work}/{inbox,tasks}.org=. Project tasks live in
the =Tasks= heading of a selected project note under =roam/DOMAIN/projects/=.
Existing files outside this convention can be included with
=et/org-extra-agenda-files=; nothing is moved or scanned across the whole vault.

Capture creates only its selected destination's parents. Starting Emacs does
not create notes, index the vault, or connect to a graph server. Agenda sources
are refreshed explicitly on agenda invocation and after capture, scanning only
the designated project-note directories, not every topic/research/daily note.
Personal/work agendas include general projects; the all view includes both.

Domain defaults are workspace-local when Perspective is active and can be set
with =SPC n D=. A domain-specific note overrides the workspace default. General
notes are shared organizationally, not by a privacy/security boundary.

Capture keys: =SPC X= opens the general menu; =pi= personal inbox, =pt= personal
TODO, =ph= daily personal habit, =wi= work inbox, =wt= work TODO, =j= project
task. Only the habit template
introduces a schedule/repeater; normal TODOs have no invented dates/deadlines.
The initial daily habit schedule is editable before finalizing.

                         (<= (org-time-string-to-absolute due) last)
                       (error nil))))
      (line-end-position))))

(defun et/capture-template-add (key description type target-type file headline template)
  "Create and persist an Org capture template.

are prompted for interactively.  TARGET-TYPE is either
\"file+headline\" or \"file\"."
  (interactive
   (let* ((key (string-trim (read-string "Template key: ")))
          (description (string-trim (read-string "Description: ")))

  (when (string-match-p "[ \t]" key) (user-error "Template keys cannot contain spaces"))

* Pomodoro and habits

=org-pomodoro= remains available at =SPC m p= and is not modified. The new
=et/pomodoro-start= helper at =SPC m P= is an independent, inspectable cycle:
four 25-minute work segments, 5-minute breaks between them, then a 30-minute
break. Every segment is recorded as a TODO in =DOMAIN/pomodoro.org=; work
segments prompt for "Planned work" at the start and "What was achieved?" at the
end. =SPC m L= lists work segments for an Org-style date range (default Monday
of this week through today). Compare both helpers and keep the preferred one.

=et/new-habit= creates an Org habit with an explicit frequency and objective.
When the objective is reached the habit is archived under
=DOMAIN/habits-archive.org=; =et/restart-habit= copies it back with a fresh
count. =et/pomodoro-trial-habit= creates five weekly weekday habits (Mon–Fri)
for one month so both pomodoro helpers can be compared.

(defun et/restart-habit (&optional heading)
  "Copy an archived habit back into the active habits file."
  (interactive)
  (let* ((domain (et/current-domain))
         (archive (expand-file-name (concat domain "/habits-archive.org")
                                    et/notes-directory))
         (target (et/habit-file domain)))
    (unless (file-readable-p archive)
      (user-error "No archived habits for domain %s" domain))
    (let* ((headings
            (with-current-buffer (find-file-noselect archive)
              (delq nil
                    (org-map-entries
                     (lambda ()
                       (when (org-entry-get nil "ET_HABIT_ARCHIVED")
                         (org-get-heading t t t t)))
                     nil 'file))))
           (heading (or heading
                        (completing-read "Restart habit: " headings nil t))))
      (unless (member heading headings)
        (user-error "No archived habit named %s" heading))
      (let ((subtree
             (car
              (delq nil
                    (with-current-buffer (find-file-noselect archive)
                      (org-map-entries
                       (lambda ()
                         (when (equal (org-get-heading t t t t) heading)
                           (org-back-to-heading t)
                           (buffer-substring-no-properties
                            (point) (org-end-of-subtree t t))))
                       nil 'file))))))
        (with-current-buffer (find-file-noselect target)
          (widen)
          (goto-char (point-min))
          (unless (re-search-forward "^\\* Habits[ \t]*$" nil t)
            (goto-char (point-max))
            (unless (bolp) (insert "\n"))
            (insert "* Habits\n")
            (goto-char (point-min))
            (re-search-forward "^\\* Habits[ \t]*$" nil t))
          (org-back-to-heading t)
          (org-end-of-subtree t)
          (unless (bolp) (insert "\n"))
          (insert "\n" subtree)
          (goto-char (point-max))
          (org-back-to-heading t)
          (org-todo "TODO")
          (dolist (property '("ET_HABIT_ARCHIVED" "ET_HABIT_RESULT"
                              "ARCHIVE_TIME" "ARCHIVE_FILE" "ARCHIVE_OLPATH"
                              "ARCHIVE_CATEGORY" "ARCHIVE_TODO"))
            (org-entry-delete nil property))
          (org-entry-put nil "ET_HABIT_COMPLETED" "0")
          (let ((interval
                 (et/habit-interval
                  (string-to-number
                   (or (org-entry-get nil "ET_HABIT_FREQUENCY") "3"))))
                (date (format-time-string "%Y-%m-%d")))
            (org-schedule nil date)
            (save-excursion
              (org-back-to-heading t)
              (when (re-search-forward "^SCHEDULED: <[^>]+>" (line-end-position) t)
                (replace-match (format "SCHEDULED: <%s .+%dd>" date interval)))))
          (save-buffer))
        (message "Restarted habit: %s" heading)))))

* Org-roam: domains, research, dailies, and graph

=org-roam= supplies stable IDs, aliases, tags, backlinks, and a disposable local
SQLite index. =org-roam-ui= supplies an interactive browser graph, started only
by =SPC n r g=. The graph/database include ALL domains: filters are not security.
SQLite support must be available in Emacs. Do not sync the live database with
Syncthing; sync source notes/attachments and rebuild each machine's index.

Find/insert default to the current domain plus general; a prefix argument shows
all domains. Unknown-layout legacy nodes remain available through all-domain
lookup; we never migrate them automatically. Capture asks a domain explicitly.
File-level aliases and subject tags use upstream commands, not a parallel index.

Completion labels show file nodes by title and heading nodes as
=Document title -> Parent heading -> Heading=. The indexed outline path includes
parents without IDs too. This is display-only: note titles, IDs, and inserted
link descriptions are not rewritten. The same display setting applies to both
our scoped commands and upstream =org-roam-node-find=, including alias candidates.

Dailies use =DOMAIN/daily/YYYY-MM-DD.org=. Short journal, work log, and meeting
entries share that day's file. Work logs insert a link to the currently clocked
task, not duplicate clock records. Weekly reviews link seven existing/missing
daily entries without creating them. Vocabulary is a drill-tagged question and
answer in a roam note. Citations use Org Cite + Citar and your own BibTeX files;
Zotero is optional, not a prerequisite.

* Development: languages, Eglot, and containers

Built-in =Eglot=, =Flymake=, =Xref= and =Eldoc= provide language-server integration,
diagnostics, navigation and documentation. Corfu displays their standard CAPFs.
There is no lsp-mode/Flycheck overlap, server auto-installation, or format-on-save.
Servers start explicitly with =SPC m l=. Opening code, including remote files,
does not start a server, run tests, query a database, or contact Docker.

** Modes and servers

Python, JavaScript, C, C++, Java and SQL use built-in modes. =typescript-mode=
adds TypeScript, =web-mode= supplies TSX without requiring a grammar,
=yaml-mode= adds YAML, =yara-mode= adds YARA syntax, and =dockerfile-mode= /
=et/compose-mode= handle container definitions. Compose is a small YAML-derived
mode: the old docker-compose-mode is not available in our archives, and does not
justify a separate Git bootstrap. =docker= provides explicit
Docker management commands, not an automatic daemon connection.

Installed tree-sitter grammars enable built-in Python/JS/TS/TSX/Java/C/C++/
YAML/Dockerfile modes per buffer; absent grammars fall back without downloads.
No grammar is installed or compiled on ordinary startup. Compose remains in its
dedicated YAML-derived mode so its commands and filename detection remain useful.
C and C++ use clangd through Eglot's built-in mappings; =compile_flags.txt= or
=compile_commands.json= lets clangd resolve the project's build flags.

| Language | External server (install separately) |
|----------+--------------------------------------|
| Python | basedpyright-langserver (preferred); pyright/pylsp fall back automatically |
| JavaScript/TypeScript/TSX | typescript-language-server --stdio, plus TypeScript |
| C/C++ | clangd, using =compile_flags.txt= or =compile_commands.json= |
| YAML/Compose | yaml-language-server --stdio (Compose is YAML; schema setup is separate) |
| Java | jdtls (requires a compatible JDK), or Eglot's java-language-server alternative |
| SQL | sqls; configure dialect/connections deliberately, no stored credentials here |
| Dockerfile | docker-langserver --stdio |
| YARA | yr-ls, through Emacs 31's built-in Eglot mapping |

Eglot's built-in server mappings are retained except for adding our mode variants
and SQL. SQL evaluation/REPL uses built-in sql.el, only when explicitly invoked.
YARA matching runs rules against data, not just syntax checks, so no automatic
matching/validation command runs on opening or saving a rule.

** Environments, commands, and boundaries

Python buffers discover a virtualenv automatically: =.venv= beside the current
file, then =.venv=, =venv=, =env=, =.virtualenv=, or =virtualenv= at the project
root, then =VIRTUAL_ENV=. If none is usable, Emacs asks once per project whether
to choose one; =SPC m v= remains an explicit override. Selection updates PATH,
=exec-path=, =VIRTUAL_ENV=, =python-shell-interpreter=, and
=python-shell-virtualenv-root= in the buffer. The REPL prefers the venv's
=ipython3= (with =--simple-prompt=), falling back to its plain =python= when
IPython is absent. New Python buffers in the same project reuse an explicit
choice; already-open buffers keep their local state. Nothing assumes
Poetry/Conda/uv conventions. The selected environment is propagated to the
Eglot server process so =basedpyright-langserver= (the preferred Python server)
analyses against that venv through =VIRTUAL_ENV=. Project-local
=node_modules/.bin= is added when
=SPC m l=, a test command, or =SPC m F= runs in a local JS/TS project. This
executes project-provided tools, so use only in trusted projects. Remote
interpreter/server paths must be configured explicitly.

Build uses =SPC m c= (Projectile, prompting for your command). Tests use =SPC m t=,
=SPC m T= and =SPC m u=: pytest for Python, and a detected Jest/Vitest runner (or
an arbitrary command via =SPC m c=) for JS/TS. Nothing runs tests or formatting
on save. Formatting is =SPC m f= (LSP server, if it supports it) or =SPC m F=
(standalone: Ruff for Python, Prettier for JS/TS, clang-format for C/C++).
Standalone formatters and test runners are never installed or selected silently.

Docker management is =SPC p D=. =SPC m V= validates a Compose file through
=docker compose -f FILE config --quiet= after asking to save changes. It refuses
unsaved/remote files: Docker contexts, SSH file paths and remote-container LSP
are distinct workflows still to be configured/tested against your topology.
Use explicit =docker context use NAME= or =DOCKER_HOST= settings for remote CLI
management; this configuration does not switch contexts or deploy containers.
Compose validation can read .env files but uses --quiet to avoid dumping resolved
secrets into the compilation buffer. No automatic up/build/prune actions.

** Testing and formatting

Python tests run through =python -m pytest=, so the =pytest= of the selected
virtualenv is used. =SPC m t= runs the whole suite, =SPC m T= the current file, and
=SPC m u= the test at point (resolved to =file::Class::method= from the enclosing
class/def). JS/TS tests detect the runner from =package.json=: =vitest= or =jest=
in =devDependencies=, or the =test= script; =SPC m t= falls back to =npm test=,
while file/point scopes require a detected runner and pass =-t <name>= for the
enclosing =test=/=it=/=describe=. Commands run in a compilation buffer under the
project root with the buffer's environment, so they stay explicit and visible.

Standalone formatting is =SPC m F=: Ruff for Python (=ruff format FILE=),
Prettier for JS/TS (=prettier --write FILE=), and clang-format for C/C++
(=clang-format -i FILE=). It refuses unsaved buffers, quotes the path, and
reloads the buffer only after the formatter reports success. A missing formatter
is a clear error, not an auto-install. These complement, not replace, =SPC m f=
(LSP formatting) and the language-server diagnostics already provided by
Eglot/Flymake.

Debugging uses =dape= with the adapter selected by the project's =.dir-locals.el=
or the =dape= prompt. =SPC m D s= starts a session after a Python preflight:
missing =debugpy= produces an actionable error instead of a session that cannot
connect, and debugpy is launched on =127.0.0.1= rather than relying on how
=localhost= resolves. =SPC m D b= marks or unmarks a breakpoint at point,
=SPC m D e= enables or disables it without removing it, and =SPC m D B= removes
all breakpoints. =SPC m D l/E/h/F= add log, conditional, hit-count, and function
breakpoints. =SPC m D c/n/i/o= continue, step over, step in, and step out;
=SPC m D r= opens the Dape REPL and =SPC m D q= quits. Dape's =gdb= configuration
requires GDB 14.1 or newer; =lldb-dap= is an alternative for C/C++. Debug adapters
and debuggee programs are never started just by opening a source file.

A breakpoint can also run code when it is hit. With point on an existing
breakpoint, =SPC m D a= registers a debuggee expression (evaluated in the
stopped frame's language), an Emacs Lisp expression, a shell command, or a
script file. Scripts use the interpreter implied by their extension (Python,
JavaScript/TypeScript, shell, Emacs Lisp, Ruby, or Java) and run from the
project root. =SPC m D A= clears the action. Actions are stored for the current
session only and run from =dape-stopped-hook= when Dape reports a breakpoint
stop at that file and line.

For the Python example, install =debugpy= in the interpreter Dape will use
(for example =python -m pip install debugpy=) or select a virtualenv with
=SPC m v= before =SPC m D s=. C/C++ examples compile with =make= first.

A local =examples/= tree, ignored by Git, provides disposable programs for every
supported language. Python, JavaScript/TypeScript, Java, C and C++ include Dape
configurations; YAML, SQL, YARA, Dockerfile, Compose, TSX, Bash and JSON exercise
editing, LSP, tree-sitter and compilation only. Each example has a =.projectile=
marker so Projectile and Dape use the example directory as the project root.

(defun et/dape--action-at-point ()
  "Return the breakpoint action registered for the current line."
  (alist-get (et/dape--action-key) et/dape-breakpoint-actions nil nil #'equal))

(defun et/dape-python-debugpy-available-p (&optional python)
  "Return non-nil when PYTHON can import the debugpy adapter."
  (let ((python (or python (executable-find "python")))
        (process-environment process-environment))
    (and python
         (with-temp-buffer
           (zerop (call-process python nil t nil
                                "-c" "import debugpy.adapter"))))))

(defun et/dape-python-preflight ()
  "Fail clearly when Python cannot load the debugpy adapter."
  (let ((python (executable-find "python")))
    (unless python
      (user-error "Python executable not found; install Python or select a virtualenv with SPC m v"))
    (unless (et/dape-python-debugpy-available-p python)
      (user-error "Python debug adapter debugpy is not installed for %s; run `%s -m pip install debugpy' or select a virtualenv that has it with SPC m v"
                  python python))))

(defun et/dape-start ()
  "Start Dape, checking Python's debug adapter first."
  (interactive)
  (when (derived-mode-p 'python-mode 'python-ts-mode)
    (et/dape-python-preflight))
  (call-interactively #'dape))

(defun et/dape-toggle-breakpoint-enabled ()
  "Enable or disable source breakpoints at point without removing them."
  (interactive)
  (require 'dape)
  (let ((breakpoints (dape--breakpoints-at-point))
        sources)
    (unless breakpoints
      (user-error "No breakpoint at point"))
    (dolist (breakpoint breakpoints)
      (when (dape--source-breakpoint-p breakpoint)
        (dape--breakpoint-disable
         breakpoint (not (dape--breakpoint-disabled breakpoint)))
        (push (dape--breakpoint-source breakpoint) sources)))
    (unless sources
      (user-error "Point has no source breakpoint"))
    (apply #'dape--breakpoint-notify-changes sources)
    (message "Breakpoint toggled at line %d" (line-number-at-pos))))

(defun et/dape--script-interpreter (file)
  "Return a command prefix for running script FILE."
  (pcase (downcase (or (file-name-extension file) ""))
    ((or "py" "pyw")
     (or (and (boundp 'python-shell-interpreter)
              python-shell-interpreter)
         "python3"))
    ((or "js" "mjs" "cjs") "node")
    ("ts" "npx ts-node")
    ((or "sh" "bash") "bash")
    ("el" (concat (shell-quote-argument
                   (expand-file-name invocation-name invocation-directory))
                  " -Q --batch -l"))
    ("rb" "ruby")
    ("java" "java")
    (_ (read-string "Command/interpreter for the script: "))))

(defun et/dape--read-breakpoint-action ()
  "Read a breakpoint action from the minibuffer."
  (let ((type (completing-read
               "Breakpoint action: "
               '("Debuggee expression" "Emacs Lisp" "Shell command" "Script file")
               nil t nil nil "Debuggee expression")))
    (pcase type
      ("Debuggee expression"
       (let ((value (read-string "Expression in the debuggee's language: ")))
         (when (string-empty-p value)
           (user-error "Empty debuggee expression"))
         (list :type 'debuggee :value value)))
      ("Emacs Lisp"
       (let ((value (read-string "Emacs Lisp expression: ")))
         (when (string-empty-p value)
           (user-error "Empty Emacs Lisp expression"))
         (list :type 'elisp :value value)))
      ("Shell command"
       (let ((value (read-string "Shell command (runs in the project root): ")))
         (when (string-empty-p value)
           (user-error "Empty shell command"))
         (list :type 'command :value value)))
      ("Script file"
       (let* ((file (expand-file-name (read-file-name "Script: " nil nil t)))
              (interpreter (et/dape--script-interpreter file)))
         (unless (file-regular-p file)
           (user-error "Not a regular script file: %s" file))
         (list :type 'script :value file :interpreter interpreter))))))

(defun et/dape-set-breakpoint-action ()
  "Set an action to run when the breakpoint at point is hit."
  (interactive)
  (require 'dape)
  (unless (dape--breakpoints-at-point)
    (user-error "Set a breakpoint here first with SPC m D b"))
  (let* ((key (et/dape--action-key))
         (action (et/dape--read-breakpoint-action)))
    (setf (alist-get key et/dape-breakpoint-actions nil nil #'equal) action)
    (message "Breakpoint action set for %s:%d"
             (file-name-nondirectory (car key)) (cdr key))))

(defun et/dape-clear-breakpoint-action ()
  "Remove the breakpoint action at point."
  (interactive)
  (let* ((key (et/dape--action-key))
         (action (et/dape--action-at-point)))
    (unless action
      (user-error "No breakpoint action at point"))
    (setq et/dape-breakpoint-actions
          (seq-remove (lambda (pair) (equal (car pair) key))
                      et/dape-breakpoint-actions))
    (message "Breakpoint action cleared for %s:%d"
             (file-name-nondirectory (car key)) (cdr key))))

(defun et/dape--run-breakpoint-action (conn action)
  "Run ACTION for stopped CONN."
  (pcase (plist-get action :type)
    ('debuggee
     (dape-evaluate-expression conn (plist-get action :value) "repl"))
    ('elisp
     (condition-case err
         (eval (car (read-from-string (plist-get action :value))) t)
       (error
        (message "Breakpoint Emacs Lisp action failed: %s"
                 (error-message-string err)))))
    ('command
     (let ((default-directory (or (et/dev-project-root) default-directory)))
       (async-shell-command (plist-get action :value))))
    ('script
     (let* ((file (plist-get action :value))
            (interpreter (or (plist-get action :interpreter)
                             (et/dape--script-interpreter file)))
            (default-directory (or (et/dev-project-root) default-directory)))
       (async-shell-command
        (format "%s %s" interpreter (shell-quote-argument file)))))
    (_
     (message "Unknown breakpoint action type: %S"
              (plist-get action :type)))))

(defun et/dape--stopped-breakpoint-context ()
  "Return (CONN FILE . LINE) when stopped at a breakpoint."
  (when-let* ((conn (dape--live-connection 'stopped t))
              (reason (format "%s" (or (dape--state-reason conn) "")))
              ((string-match-p "breakpoint" reason))
              (frame (dape--current-stack-frame conn))
              (marker (dape--object-to-marker conn frame))
              (buffer (marker-buffer marker))
              (file (buffer-file-name buffer)))
    (list conn
          (cons (et/dape--canonical-file file)
                (line-number-at-pos (marker-position marker))))))

(defun et/dape-run-breakpoint-actions (&optional attempts)
  "Run the action registered for the breakpoint where Dape stopped.
Dape populates stack frames asynchronously, so retry briefly when
the stopped frame is not available yet. ATTEMPTS is an internal
retry counter."
  (let ((attempts (or attempts 0)))
    (condition-case err
        (if-let* ((context (et/dape--stopped-breakpoint-context)))
            (when-let* ((location (nth 1 context))
                        (action (alist-get location et/dape-breakpoint-actions
                                           nil nil #'equal)))
              (et/dape--run-breakpoint-action (car context) action))
          (when (< attempts 20)
            (run-with-timer 0.1 nil #'et/dape-run-breakpoint-actions
                            (1+ attempts))))
      (error
       (message "Dape breakpoint action failed: %s"
                (error-message-string err))))))

  :config
  (setq dape-cwd-function #'et/dev-project-root)
  (dape-breakpoint-global-mode 1)
  ;; Prefer IPv4 loopback explicitly. Some systems resolve "localhost" to
  ;; ::1 while debugpy listens only on IPv4, leaving Dape waiting for a
  ;; connection that never arrives.
  (dolist (name '(debugpy debugpy-module))
    (when-let* ((config (alist-get name dape-configs)))
      (plist-put config 'host "127.0.0.1")
      (plist-put config 'command-args
                 '("-m" "debugpy.adapter" "--host" "127.0.0.1"
                   "--port" :autoport))))
  (add-hook 'dape-stopped-hook #'et/dape-run-breakpoint-actions))
